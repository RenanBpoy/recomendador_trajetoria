# Recomendador de Trajetória — Frontend

## Tecnologias

- React
- Vite
- React Router

## Configuração

Instale as dependências:

```powershell
npm install
```

Se necessário, copie `.env.example` para `.env` e configure a URL da API:

```env
VITE_API_URL=http://localhost:8000/api/v1
```

## Execução

Inicie primeiro a API e depois execute:

```powershell
npm run dev
```

O endereço padrão do Vite é `http://localhost:5173`.

## Validação

```powershell
npm test
npm run lint
npm run build
```
